# Home-side setup

| Host | Needs |
|---|---|
| backup host (`tag:backup`) | user `edge-backup`; `authorized_keys` line printed by the deploy run: `restrict,command="rrsync -wo ~/headscale" ssh-ed25519 …`; then put `ssh-keyscan backup.ts.natanddavehouse.com` output into `backup_host_known_hosts` |
| Proxmox (`tag:pve`) | `pve-heartbeat.timer`, every 60 s, installed by `tools/pve-setup.py heartbeat` (`docs/runbooks/proxmox-setup.md`): `success=true` only while `zpool status -x`, NVMe SMART and pool capacity (< 85%) are healthy, otherwise `success=false&error=<cause>` to `https://status.ts.natanddavehouse.com/api/v1/endpoints/home_proxmox-heartbeat/external` (`$TOKEN` = `gatus_heartbeat_pve_token` from `secrets/edge.sops.yaml`); silence for 3 min alerts |
| app VM (`tag:xstockstrat`, hostname `xstockstrat`) | Debian 13 VM, 4 cores / 8 GiB / 40G, converged by **app-host** (`deploy-compose-app.md` §1.1). xstockstrat env: `APP_URL=https://xstockstrat.natanddavehouse.com` (`AGENT_PUBLIC_URL`/`UI_BASE_URL` derive from it, `deploy-compose-app.md` §4.1); config key `agent.oauth.allowed_redirect_uris=https://claude.ai/api/mcp/auth_callback,https://claude.com/api/mcp/auth_callback` |
| staging app VM (`tag:xstockstrat-staging`, hostname `xstockstrat-staging`) | Same shape as the app VM, with its **own** database, role, encryption keys and `APP_URL=https://xstockstrat-staging-ui.ts.natanddavehouse.com:8443`; reaches only `tag:db` 5432/6432 and `tag:edge:8443`. Served by the edge at `https://xstockstrat-staging-ui.ts.natanddavehouse.com:8443` (tailnet-only; UI 3000, `/agent` 9000). See `onboard-service.md`. |
| DB host (`tag:db`) | Built and converged by `playbooks/db.yml` (`docs/runbooks/db-host.md`). pgBackRest **2.59.2** running its own TLS server on 8432 (the edge pulls backups) and pushing WAL with `repo1-host=edge.ts.natanddavehouse.com`, `repo1-host-type=tls`; client cert/key + CA from `secrets/edge.sops.yaml` (`pgbackrest_tls_client_*`, CN `db-pgbackrest`). PostgreSQL 18, data dir `/var/lib/postgresql/18/main`; the edge backs it up at 03:00 Los Angeles time (Sunday full, other days differential), skipped until the stanza exists, and pushes `edge_pgbackrest-backup` to Gatus after each success (silence for 26 h alerts). PgBouncer listens on 6432. Heartbeat: `db-heartbeat.timer` inside the container, every 5 min, installed from the Proxmox host by `tools/pve-setup.py db-heartbeat` (`docs/runbooks/proxmox-setup.md`): `success=true` only while `pg_isready` answers on 5432 and 6432, 8432 accepts connections and the data directory's filesystem is under 85%, otherwise `success=false&error=<postgres pgbouncer pgbackrest disk-full disk-unreadable>` to `https://status.ts.natanddavehouse.com/api/v1/endpoints/home_db-heartbeat/external` (token = `gatus_heartbeat_db_token` from `secrets/edge.sops.yaml`); silence for 11 min alerts. |
