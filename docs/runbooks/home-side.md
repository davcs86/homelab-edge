# Home-side setup

| Host | Needs |
|---|---|
| backup host (`tag:backup`) | user `edge-backup`; `authorized_keys` line printed by the deploy run: `restrict,command="rrsync -wo ~/headscale" ssh-ed25519 …`; then put `ssh-keyscan backup.ts.natanddavehouse.com` output into `backup_host_known_hosts` |
| Proxmox (`tag:pve`) | systemd timer, every 60 s: `curl -fsS -X POST -H "Authorization: Bearer $TOKEN" "https://status.ts.natanddavehouse.com/api/v1/endpoints/home_proxmox-heartbeat/external?success=true"` (`$TOKEN` = `gatus_heartbeat_pve_token` from `secrets/edge.sops.yaml`); silence for 3 min alerts |
| app VM (`tag:xstockstrat`, hostname `xstockstrat`) | xstockstrat env: `AGENT_PUBLIC_URL=https://xstockstrat.natanddavehouse.com/agent`, `UI_BASE_URL`/`APP_URL=https://xstockstrat.natanddavehouse.com`; config key `agent.oauth.allowed_redirect_uris=https://claude.ai/api/mcp/auth_callback,https://claude.com/api/mcp/auth_callback` |
| staging app VM (`tag:xstockstrat-staging`, hostname `xstockstrat-staging`) | Same shape as the app VM, with its **own** database, role, encryption keys and `AGENT_PUBLIC_URL`; reaches only `tag:db` 5432/6432 and `tag:edge:8443`. Served by the edge at `https://xstockstrat-staging-ui.ts.natanddavehouse.com:8443` (tailnet-only; UI 3000, `/agent` 9000). See `onboard-service.md`. |
| DB host (`tag:db`) | pgBackRest **2.59.2** running its own TLS server on 8432 (the edge pulls backups) and pushing WAL with `repo1-host=edge.ts.natanddavehouse.com`, `repo1-host-type=tls`; client cert/key + CA from `secrets/edge.sops.yaml` (`pgbackrest_tls_client_*`, CN `db-pgbackrest`). Backup schedule on the edge is pending the PG version and data dir. PgBouncer listens on 6432. Heartbeat: systemd timer, every 5 min: `curl -fsS -X POST -H "Authorization: Bearer $TOKEN" "https://status.ts.natanddavehouse.com/api/v1/endpoints/home_db-heartbeat/external?success=true"` (`$TOKEN` = `gatus_heartbeat_db_token` from `secrets/edge.sops.yaml`); silence for 11 min alerts. |
